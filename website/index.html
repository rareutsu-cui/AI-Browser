非公式 Ubuntu 向け修正版 ／ amd64

AI-Browser：Linux版
独自ビルド

AI-Browser v2.0.3 を基に、Ubuntu で使うために 画面配置と起動時の読み込みを変更した自家版です。

配布について

動作確認済みの Ubuntu／amd64 向け deb を公開しています。非公式修正版の第1版（v2.0.3-linux.1）です。

deb をダウンロード（約10.3 MB）

SHA256SUMS をダウンロード ／ リリース詳細

deb と SHA256SUMS を同じフォルダへ保存し、次で照合できます。

sha256sum -c SHA256SUMS

確認した SHA-256：

9c95c5fcf9a54df0b591df80782dae364a2f1c86c72fb8491f69d009b8a49e61

インストール

起動中の AI-Browser を終了し、設定・履歴の保存先 ~/.local/share/com.aibrowser.app/ をバックアップしてから、ダウンロード先で実行してください。

sudo apt install ./AI-Browser_2.0.3_amd64.deb

同じバージョンが既に入っている場合：

sudo apt install --reinstall ./AI-Browser_2.0.3_amd64.deb

AppImage は動作が安定しないため、公開を保留しています。

変更したところ

  • アドレスバー直下にチャットを表示するよう、Linux の WebView 配置を修正。
  • エディタを開閉式の下部ペインへ変更。閉じても入力内容を保持。
  • 重複する寸法通知と再配置を抑制。
  • チェック済みの AI だけを起動時に読み込み。設定変更は再起動後に反映。

確認できた動作

手元の Ubuntu 環境で deb 版の表示、下部エディタの開閉、 Muse へのエディタ送信を確認しました。 作業過程では内蔵ターミナルの入力と pwd の実行も確認しています。

制限

すべての AI サービスのログイン・送信を確認したものではありません。 Google 認証は別途確認が必要です。 初回のエディタ開閉では、がたつきが残る可能性があります。
