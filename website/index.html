バイナリtar.gzは展開して ./ai-browser で起動します。WebKitGTK 4.1・GTK 3とその依存ライブラリが必要です。

SHA256SUMSをダウンロード ／ リリース詳細

2.0.4の変更点

  • チャットとエディタのスクロールバー表示を調整しました。
  • チャット内の子フレームにも表示スタイルを適用しました。
  • 送信先メニューを有効なAIタブに合わせ、一括送信の選択を反映しました。

これまでの変更点

  • WebViewのレイアウトを変更し、チャットがアドレスバーの直下に表示されるようにしました。
  • エディタを、閉じられる下部のペインにしました。閉じても入力内容は残ります。
  • リサイズ通知の重複を抑えました。
  • 起動時に読み込むのは、有効にしたAIサービスだけです。設定変更は再起動後に反映されます。

動作確認

2.0.4は型チェック・本番ビルド・debのバージョン確認を通過しています。開発版のChatGPT・Museの読み込み完了はユーザーの起動ログで確認しました。今回の配布バイナリのGUI動作・インストール後の動作は未確認です。

以前の2.0.3独自版では、手元のUbuntu環境でdebの表示・下部エディタ・Museへの送信を確認しています。他のUbuntuバージョンやディストリビューションでの互換性は未確認です。

既知の制限

  • すべてのAIサービスについて、ログインと送信を確認したわけではありません。
  • Googleサインインは、別途確認が必要です。
  • エディタを初めて開くとき、動作がぎこちない場合があります。
  • AppImageは動作が安定しないため、今回の配布対象はdebとtar.gzです。

インストール

  1. AI-Browserを終了します。
  2. ~/.local/share/com.aibrowser.app/ をバックアップします。
  3. 上の配布ファイルから AI-Browser_2.0.4_amd64.deb と SHA256SUMS を同じフォルダにダウンロードします。
  4. ダウンロード先のフォルダで、チェックサムを確認します。
sha256sum --ignore-missing -c SHA256SUMS

AI-Browser_2.0.4_amd64.deb: OK と表示されたら、次のコマンドでインストールします。

sudo apt install ./AI-Browser_2.0.4_amd64.deb

同じバージョンがすでに入っている場合：

sudo apt install --reinstall ./AI-Browser_2.0.4_amd64.deb
