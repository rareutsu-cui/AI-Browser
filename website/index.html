AI-Browser：Linux版
独自ビルド

AI-Browser 2.0.3をベースにした、非公式のLinux版です。対象はUbuntu（amd64）です。

配布ファイル

debをダウンロード（約10.3 MB）

SHA256SUMSをダウンロード ／ リリース詳細

変更点

  • WebViewのレイアウトを変更し、チャットがアドレスバーの直下に表示されるようにしました。
  • エディタを、閉じられる下部のペインにしました。閉じても入力内容は残ります。
  • リサイズ通知の重複を抑えました。
  • 起動時に読み込むのは、有効にしたAIサービスだけです。設定変更は再起動後に反映されます。

動作確認

1つのUbuntu環境で、debパッケージのインストール後の表示、下部エディタ、エディタ内容のMuseへの送信を確認しました。

既知の制限

  • すべてのAIサービスについて、ログインと送信を確認したわけではありません。
  • Googleサインインは、別途確認が必要です。
  • エディタを初めて開くとき、動作がぎこちない場合があります。
  • AppImageは動作が安定しないため、今回の配布対象はdebパッケージです。

インストール

  1. AI-Browserを終了します。
  2. ~/.local/share/com.aibrowser.app/ をバックアップします。
  3. 上の配布ファイルから AI-Browser_2.0.3_amd64.deb と SHA256SUMS を同じフォルダにダウンロードします。
  4. ダウンロード先のフォルダで、チェックサムを確認します。
sha256sum -c SHA256SUMS

AI-Browser_2.0.3_amd64.deb: OK と表示されたら、次のコマンドでインストールします。

sudo apt install ./AI-Browser_2.0.3_amd64.deb

同じバージョンがすでに入っている場合：

sudo apt install --reinstall ./AI-Browser_2.0.3_amd64.deb

チェックサム

SHA256SUMSを添付しています。ダウンロードしたファイルのチェックサムを照合し、配布ファイルと一致しているか確認できます。
