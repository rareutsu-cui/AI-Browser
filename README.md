# AI-Browser：Linux版（独自ビルド）

AI-Browser v2.0.3 を基に、Ubuntu 向けに再構成した非公式の自家版です。
原作者・公式プロジェクトとは独立しており、公式の承認やサポートを示すものではありません。

## 紹介・配布ページ

https://ai-browser-linux.pages.dev/

## 2.0.4 の更新内容（2026-11-14）

- Linux のチャット画面とエディタでスクロールバーの表示を調整。
- チャット内の子フレームにも表示スタイルを適用。
- 送信先メニューを有効な AI タブに合わせ、一括送信の選択を反映。
- 開発版で ChatGPT・Muse の起動と読み込み完了を確認（ユーザーの起動ログによる）。

## この版の変更点

- Linux の WebView 配置を修正し、アドレスバー直下にチャットを表示。
- エディタを開閉式の下部ペインへ変更。
- 重複した寸法通知と再配置を抑制。
- 起動時はチェック済みの AI だけを読み込む。
- AI の選択変更は再起動後に反映。

## 動作確認

手元の Ubuntu 環境で deb 版の表示、下部エディタの開閉、
Muse へのエディタ送信を確認しています。

すべての AI サービスのログイン・送信を確認したものではありません。
Google 認証は別途確認が必要です。
初回のエディタ開閉には、がたつきが残る可能性があります。

## 配布形式

- deb（amd64）：2.0.4をビルド済み。インストール後の動作確認は未実施。
- 実行バイナリ tar.gz（amd64）：WebKitGTK 4.1・GTK 3などが必要。
- ソースコード tar.gz：再ビルド用。依存パッケージは別途取得。
- AppImage：動作が安定しないため公開保留。

独自版の現在のバージョンは **2.0.4** です。本家 v2.0.3 を基にした非公式版で、本家の公式配布版とは内容が異なります。
2.0.4 の deb（amd64）はビルド済みです。型チェックと本番ビルドは通過しました。
この deb のインストール後の動作確認と GitHub Release への公開は未実施です。

## ビルド

Node.js 22以上、Rust stable、Linux用Tauri開発依存が必要です。

1. `npm ci`
2. `npm run typecheck`
3. `npm run tauri -- build --bundles deb`
