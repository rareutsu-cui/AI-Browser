# AI-Browser：Linux版（独自ビルド）

AI-Browser v2.0.3 を基に、Ubuntu 向けに再構成した非公式の自家版です。
原作者・公式プロジェクトとは独立しており、公式の承認やサポートを示すものではありません。

## 紹介・配布ページ

https://ai-browser-linux.pages.dev/

## この版の変更点

- Linux の WebView 配置を修正し、アドレスバー直下にチャットを表示。
- エディタを開閉式の下部ペインへ変更。
- 重複した寸法通知と再配置を抑制。
- 起動時はチェック済みの AI だけを読み込む。
- AI の選択変更は再起動後に反映。

## 動作確認

手元の Ubuntu 環境で deb 版の表示、下部エディタの開閉、
Muse へのエディタ送信を確認しています。

すべての AI サービスのログイン・送信を確認したものではありません。
Google 認証は別途確認が必要です。
初回のエディタ開閉には、がたつきが残る可能性があります。

## 配布形式

- deb（amd64）：動作確認済み。配布準備中。
- AppImage：動作が安定しないため公開保留。

バージョン表記は2.0.3ですが、本家の公式配布版とは内容が異なります。

## ビルド

Node.js 22以上、Rust stable、Linux用Tauri開発依存が必要です。

1. `npm ci`
2. `npm run typecheck`
3. `npm run tauri -- build --bundles deb`
